# Проверка Threadgoon 6.1.0

Дата: 5 октября 2026. Компьютер: Apple Silicon, macOS 26.6.2, Swift 6.3.3, встроенный Python 3.14.3. Deployment target окна — macOS 14; это не заменяет запуск на macOS 14.

## Автоматическая проверка

- `pytest`: 44 теста, включая исходные 18 сценариев и регрессии движка.
- `swift build`: успешная release-сборка окна через Swift Package Manager.
- `swift test`: 8 тестов Swift Testing. Проверены UTF-8 framing, JSON-контракт, nullable размеры, фильтры состояний, настоящий обмен Swift/Python, блокировка второй копии движка, принудительное падение и повторный запуск.
- Терминальный интерфейс: headless Textual Pilot проходит поиск, подготовку, подтверждение и переход в загрузки с общим контроллером.
- `smoke_bundle.py`: копия `.app` в папке с пробелами запускает встроенный движок при отсутствующих `PYTHONHOME`/`PYTHONPATH`, создаёт отдельную рабочую папку, отвечает на snapshot и корректно завершается.
- `codesign --verify --deep --strict`: тестовая ad hoc подпись проходит проверку.
- Приложение, перенесённое в отдельную временную папку, вручную открыло окно и встроенный движок; смена рабочей папки прошла успешно.

Регрессии Python покрывают сохранение точной статистики при обновлении каталога, актуальные фильтры при подготовке, независимую отмену операций, отсутствие дублей, сбои подготовки/нехватку места, паузу и отмену очереди, Range и сохранение `.part`, восстановление после остановки, миграцию с резервной копией, офлайн-кэш, 404/429, общий API-лимит и условные запросы. Ошибка перед началом загрузки переводит задание в `failed` и не запускает его бесконечно.

## Ручная проверка окна

Проверки выполнялись в отдельной disposable-папке `.build/ui-workspace`; существующая база пользователя не использовалась как тестовая.

- Выбор досок, поиск по названию, обновление списка, защита пустого выбора.
- Быстрый поиск, запуск через Enter, пустые результаты, миниатюры и боковая панель.
- Изменение расширений и размера: старое вложение исключается из новой подготовки.
- Точный поиск: постепенные результаты, пауза, продолжение и отмена. Полный поиск на небольшом наборе проверен автоматическими тестами; живой каталог вручную остановлен после проверки управления.
- Подтверждение количества/объёма и отмена подготовки; реальная небольшая загрузка `/po/` завершилась с проверкой размера.
- Очередь с локальным HTTP-сервером: продолжение, пауза активного файла с `.part`, отмена выбранного, подтверждение ожидающего, повтор ошибок, завершённые файлы.
- Открытие JPEG в «Просмотре» и выделение файла в Finder.
- Добавление наблюдения, выключенная по умолчанию автозагрузка, переключение автозагрузки, пауза/продолжение, отмена удаления и удаление тестового наблюдения.
- Настройки через ⌘,, сохранение, диагностика/обновление журнала, справка и Escape.
- Светлая и тёмная темы; русские системные меню.
- Закрытие и повторное открытие главного окна через ⌘1, корректный выход через ⌘Q.
- При закрытом главном окне рабочая папка остаётся заблокированной живым движком; при открытии через ⌘1 введённый запрос сохраняется.
- Исправлено перекрытие нижних кнопок строкой состояния. Проверено окно с минимальной высотой содержимого 620 pt: выбранный тред, открытые подробности и раскрытые фильтры; «Наблюдать» и «Скачать выбранное» видны полностью. В разделе завершённых загрузок «Открыть» и «Показать в Finder» также видны полностью. После исправления повторно прошли все 8 Swift-тестов.

Миграция схемы 1 → 2 проверена с сохранением записей и резервным копированием базы и конфигурации в `.threadgoon/backups/`. Рабочие базы, резервные копии и история пользователя не входят в репозиторий.

## Границы проверки

Запуск на отдельном Mac с macOS 14 и физически отсутствующим Python пока не выполнен. Проверка изоляции встроенного движка исключает зависимость от исходников и среды Python, но не заменяет проверку на другом компьютере. Intel и публичное распространение не входят в эту поставку. Developer ID, Hardened Runtime и нотарификация остаются следующим этапом; требования описаны в README.
